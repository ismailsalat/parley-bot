# Parley · Privacy & Safety (public-facing guide)

**Advertise without giving Parley access to your server.** The **Post a Server Free** button in the Parley hub uses Discord’s existing in-server interaction. You paste an invite, choose a category and description, confirm the preview, and wait for moderator approval. This does **not** open an account-wide authorization screen or install an app in the server you advertise.

**What an invite means.** Discord can disclose a server’s name, identifier and limited public metadata through an invite. It does **not** establish who owns or manages the server. We call these listings **unverified** and do not let their submitters represent the server in partnerships or make server-wide decisions.

**What installing Parley means.** Server managers can choose to install Parley for faster relisting and mutually approved partnerships. Discord displays the installation permissions. Normal Parley installation requests permission to see channels, send messages, embed links, read message history, create invites when needed, and use external emojis. The application also uses guild/member information and may use message content for its optional legacy self-posting flow. The standard invite does **not** ask for Administrator permissions; automatic hub setup may need additional hub-specific permissions. Installation is optional for a Free Listing.

**No surprise ad distribution.** An installed bot does not automatically send ads to every other server. Partner exchanges are accepted by both communities and delivered only to channels selected for that purpose. A guild can decline requests or disable its network participation.

**Moderation and control.** Every new Quick Post needs staff review. One unconnected listing per user is enforced in the database; each server has one listing. Connected managers are permission-checked against the live Discord server. If an unverified listing is inaccurate, contact hub staff for a correction or removal. Discord server moderation and safety policies still apply.

**No guarantee of security.** Parley cannot certify external communities merely by inspecting an invite. Exercise caution when joining unknown servers. This guide describes the implemented design, not an independent security audit or a claim of zero data access.
